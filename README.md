# Spotify Random Album

[![CI](https://github.com/kism/spotify-random-album/actions/workflows/ci.yml/badge.svg)](https://github.com/kism/spotify-random-album/actions/workflows/ci.yml)
[![site](https://img.shields.io/website?url=https%3A%2F%2Frsa.autist.network)](https://rsa.autist.network/)

Shows 5 random albums from your Spotify liked albums. 4 if you are on mobile.

## Development

```sh
npm ci
npm run dev     # http://127.0.0.1:8788/
```

Deployment is done by linking the repo in Cloudflare workers.
